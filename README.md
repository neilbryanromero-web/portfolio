# Neil Bryan Romero — Portfolio

Personal portfolio website for job applications.

## Preview locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a public repo (e.g. `neilbryanromero-web.github.io` or `portfolio`).
2. Push these files to the `main` branch.
3. Enable Pages: Settings → Pages → Deploy from `main` / root.
4. Site will be live at `https://neilbryanromero-web.github.io/` (or `/portfolio`).

## Customize before sending

- Replace `hello@example.com` with your real email (3 places in `index.html`).
- Update project descriptions or add screenshots if you have them.
- Adjust skills / experience to match the job you are applying for.
